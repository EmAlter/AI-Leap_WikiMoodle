Questa sezione presenta un esempio guidato per la creazione di ruoli, utenti e classi nel sistema su Moodle.

## Creare un ruolo
In Moodle è possibile creare un nuovo ruolo in due modi differenti:

* Creando un nuovo ruolo da zero
![type:video](assets/videos/role_part1.mp4)


* Oppure caricando il file xml di un ruolo già definito precedentemente
![type:video](assets/videos/role_part2.mp4)

Una volta creato, il ruolo sarà disponibile nel sistema e pronto per essere assegnato agli utenti.

!!! warning "ATTENZIONE"
    Questo ruolo non sarà utilizzato successivamente nelle guide, è stato creato solo a scopo dimostrativo.

## Creare una classe
Il metodo migliore per creare una nuova classe (o modificare quella già esistente) è quello di importare un file CSV contenente tutte le informazioni necessarie.
![type:video](assets/videos/class.mp4)

Una volta creata, la classe sarà disponibile nel sistema e pronta per essere assegnata agli utenti.

## Importazione di utenti e assegnazione di ruoli e classi
Una volta creati i ruoli e le classi, è possibile importare gli utenti nel sistema tramite file CSV definendo nel file il ruolo e la classe a cui ciascun utente appartiene (nel caso di utenti, come progettisti, esperti o, eventualmente moderatori, che non appartengono a nessuna classe, è possibile lasciare vuota la colonna relativa).
