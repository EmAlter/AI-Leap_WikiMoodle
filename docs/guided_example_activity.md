Questa sezione presenta un esempio guidato per l'accesso a una Raccolta di Attività e la definizione delle Attività all'interno di essa nel sistema su Moodle.

## Definire le attività
Una volta fatto l'accesso alla Raccolta di Attività (Deposito delle domande), l'ideale è creare una categoria padre che contenga tutte le attività concettualmente simili
![type:video](assets/videos/activity_part1.mp4)

Successivamente, all'interno della categoria padre appena creata, si possono inserire tutte le attività dei test
![type:video](assets/videos/activity_part2.mp4)

Queste attività conterranno tutte le domande specifiche del test
